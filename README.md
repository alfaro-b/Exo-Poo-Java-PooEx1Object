# Exercices 1 & 2 - POO Java

## Présentation

Ce projet est réalisé dans le cadre d'exercices de programmation orientée objet en Java.

## Résumé des exercices
Exercice 1 - City et Person

Création d'une classe City représentant une ville avec un nom, un pays et un nombre d'habitants.

Les exercices portent sur :   
la création et l'instanciation d'objets ;   
les getters et setters ;   
plusieurs constructeurs ;   
les méthodes d'affichage ;   
la méthode toString() ;   
le comptage du nombre d'instances de City.   

Création ensuite d'une classe Person avec un nom, un prénom, un âge, une adresse et une ville de naissance de type City.   

Exercice 2 - Filtrage de personnalités

Création de plusieurs personnalités avec leurs informations personnelles et leur ville de naissance.

Le programme affiche :

toutes les personnalités ;
uniquement les personnes nées en France ou habitant à Paris.

La population de la ville de naissance est affichée uniquement lorsqu'elle est renseignée.:
